Refquill reads PHP, TypeScript, and Rust declarations and writes one JSON API reference. The document contains signatures, type references, source locations, comments, and relationships between declarations.

The Rust CLI uses Mago for PHP. A bundled Node worker uses TypeDoc and TypeScript for TypeScript projects. PHP analysis needs neither PHP nor Composer. TypeScript analysis needs Node and your project's dependencies. Rust analysis reads compiler-generated rustdoc JSON or invokes Cargo for a selected library.

Use `@nickwelsh/refquill-fumadocs` to turn the document into Fumadocs pages, or use `@nickwelsh/refquill-schema` to build another frontend.

[React components](./typescript.mdx#react-components-and-hooks) receive component
labels and individual props with types, descriptions, defaults, and callback
signatures. React hooks keep their parameters and returns. SolidJS, Vue, and
Svelte components also receive framework-specific documentation.

```sh
npm install --save-dev @nickwelsh/refquill
npx refquill init --language typescript
npx refquill generate
```

## What generation does

A configuration selects named inputs. Each input chooses a language and source paths. Refquill analyzes every input, combines the results, validates the document, and writes it atomically.

PHP and TypeScript source modules and TypeDoc plugins do not run during analysis. Rust JSON import does not compile code. Rust Cargo inputs execute build scripts and procedural macros as part of compilation. Compiler or syntax errors stop generation and preserve the previous document. Repeated generation with unchanged sources preserves the output's bytes and modification time.
