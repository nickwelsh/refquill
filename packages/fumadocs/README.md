# @nickwelsh/refquill-fumadocs

Render Refquill API documents, JSON Schemas, manpages, and shared reference documents in a Fumadocs site.

Requires Node 22.18 or newer, Fumadocs 16, and React 19.

```sh
npm install @nickwelsh/refquill-fumadocs
```

## API references

Create a Fumadocs source from the JSON generated by [@nickwelsh/refquill](https://www.npmjs.com/package/@nickwelsh/refquill):

```ts
import { loader } from 'fumadocs-core/source';
import { createApiReference } from '@nickwelsh/refquill-fumadocs';
import { apiReferenceIcon } from '@nickwelsh/refquill-fumadocs/components';
import input from './api.generated.json';

export const reference = createApiReference({ input, baseUrl: '/api' });
export const source = loader({
    baseUrl: reference.baseUrl,
    source: reference.toFumadocsSource(),
    icon: apiReferenceIcon,
});
```

Pass `source.pageTree` to your Fumadocs layout. In the page route, look up `page` through the source and render:

```tsx
import { DocsBody, DocsPage } from 'fumadocs-ui/page';
import { ApiReference } from '@nickwelsh/refquill-fumadocs/components';
import '@nickwelsh/refquill-fumadocs/style.css';

<DocsPage full toc={page.data.toc} tableOfContent={{ enabled: false }}>
    <DocsBody>
        <ApiReference
            reference={reference}
            symbolId={page.data.symbolId}
            inputName={page.data.inputName}
            namespace={page.data.namespace}
        />
    </DocsBody>
</DocsPage>;
```

`ApiReference` includes its own heading. The source supplies navigation, a table of contents, and search data. `reference.getPageText(page.data)` exports Markdown.

Read the [integration guide](https://docs.nickwelsh.me/refquill/docs/0.x/fumadocs) for routing and search, or the [customization guide](https://docs.nickwelsh.me/refquill/docs/0.x/customization) to replace headers, badges, links, icons, and code rendering.

## Other references

The package also renders these inputs without API generation:

- [JSON Schemas](https://docs.nickwelsh.me/refquill/docs/0.x/json-schema) with `createJsonSchemaReference` and `JsonSchemaReference`.
- [Manpages](https://docs.nickwelsh.me/refquill/docs/0.x/manpages) with `createManPageReference` and `ManPageReference`.
- [Reference documents](https://docs.nickwelsh.me/refquill/docs/0.x/reference-documents) with `createReference` and `ReferencePage`.

Each adapter provides a Fumadocs source and Markdown exports. Keep generated documents separate from authored MDX and avoid overlapping their routes.
